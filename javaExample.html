Assignment 1: Car Rental Cost Calculator

This Java program uses JOptionPane to create a GUI-based car rental cost calculator. It calculates rental costs for three car types (Compact $30.50/day, Sedan $50/day, SUV $80.96/day) with different time periods (Day, Week with 15% discount, Month with 30% discount). The program uses nested switch statements for logic control and Math.round() for cost display.

import javax.swing.*;
import java.text.*;

                .parseInt(JOptionPane.showInputDialog(null, "For Day-1\nFor Week-2\nFor Month-3", "1,2 or 3"));
        switch (cartype) {
        case 1:
            switch (time) {
            case 1:
                double c_d = 30.50;
                JOptionPane.showMessageDialog(null, "total cost:$" + Math.round(c_d));
                break;
            case 2:
                double c_w = 30.50*7*(1-0.15);
                JOptionPane.showMessageDialog(null, "total cost:$" +Math.round(c_w));
                break;
            case 3:
                double c_m = 30.50*30*(1-0.30);
                JOptionPane.showMessageDialog(null, "total cost:$" + Math.round(c_m));
                break;
            default :
                JOptionPane.showMessageDialog(null,"You didn't enter 1,2 or 3 for 2 nd question");

            }
            break;

            case 1:

                break;

Assignment 2: Student Attendance & Assignment Checker

This console-based Java program validates student eligibility for exams. It calculates attendance percentage from total and attended classes, validates assignment scores, and checks if students meet exam criteria (75% minimum attendance and 50+ assignment score). The program also verifies the accuracy of manually entered total assignment scores.

import java.util.Scanner;

public class Assignment_1 {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Total number of classes:");
        double tnc = input.nextInt();
        System.out.print("Number of classes attended:");
        double nac = input.nextInt();
        System.out.print("Score of 1 assignment:");
        double asg1 = input.nextDouble();
        System.out.print("Score of 2 assignment:");
        double asg2 = input.nextDouble();
        System.out.print("Score of 3 assignment:");
        double asg3 = input.nextDouble();
        System.out.print("Score of total assignment:");
        double total = input.nextDouble();
        
        //calculation start
        double attendence = nac/tnc*100;
        double Total = asg1 +asg2 + asg3;
        
        if (Total == total)
            if (attendence < 75.0) {
                System.out.print("You can't enter to exam with less than 75% attedence");
            } else if (total < 50) {
                System.out.print("You can't enter exam to exam with less than 50 score of assignment");
            } else {
                System.out.print("You can enter exam kudos!");
            }
        else {
            System.out.print("You total score of assignment is not true!");
        }
        
        input.close();
    }
}

Assignment 3: Basic Calculator Application

This console calculator performs five arithmetic operations (addition, subtraction, multiplication, division, remainder) using a switch-case menu system. It includes proper error handling for division by zero scenarios and uses double precision for accurate calculations. The program provides user-friendly operation selection and graceful exit functionality.

import java.util.Scanner;

public class Assinment_2 {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Enter num 1:");
        double num_1 = input.nextDouble();
        System.out.print("Enter num 2:");
        double num_2 = input.nextDouble();
        System.out.print(
                "For addition:1\nFor substraction:2\nFor multiplication:3\nFor division:4\nFor remainder:5\nEnter number:");
        int operation = input.nextInt();
        
        switch (operation) {
        case 1:
            double addition = num_1 + num_2;
            System.out.print("Answer:" + addition);
            break;
        case 2:
            double substraction = num_1 - num_2;
            System.out.print("Answer:" + substraction);
            break;
        case 3:
            double multipiclation = num_1 * num_2;
            System.out.print("Answer:" + multipiclation);
            break;
        case 4:
            if (num_2 == 0) {
                System.out.print("Error!!!");
            } else {
                double divison = num_1 / num_2;
                System.out.print("Answer:" + divison);
            }
            break;
        case 5:
            if (num_2 == 0) {
                System.out.print("Error!!!");
            } else {
                double remainder = num_1 % num_2;
                System.out.print("Answer:" + remainder);
            }
            break;
        default:
            System.out.print("Bye");
            break;
        }
    }
}
