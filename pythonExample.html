Assignment 2: Student Attendance & Assignment Checker

This console-based Java program validates student eligibility for exams. It calculates attendance percentage from total and attended classes, validates assignment scores, and checks if students meet exam criteria (75% minimum attendance and 50+ assignment score). The program also verifies the accuracy of manually entered total assignment scores.

        double asg3 = input.nextDouble();
        System.out.print("Score of total assignment:");
        double total = input.nextDouble();
        
        //calculation start
        double attendence = nac/tnc*100;
        double Total = asg1 +asg2 + asg3;
        
        if (Total == total)
            if (attendence < 75.0) {
                System.out.print("You can't enter to exam with less than 75% attedence");

Assignment 3: Basic Calculator Application

This console calculator performs five arithmetic operations (addition, subtraction, multiplication, division, remainder) using a switch-case menu system. It includes proper error handling for division by zero scenarios and uses double precision for accurate calculations. The program provides user-friendly operation selection and graceful exit functionality.

import java.util.Scanner;

public class Assinment_2 {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Enter num 1:");
        double num_1 = input.nextDouble();
        System.out.print("Enter num 2:");
        double num_2 = input.nextDouble();
        System.out.print(
                "For addition:1\nFor substraction:2\nFor multiplication:3\nFor division:4\nFor remainder:5\nEnter number:");
        int operation = input.nextInt();
        
        switch (operation) {
        case 1:
            double addition = num_1 + num_2;
            System.out.print("Answer:" + addition);
            break;
        case 2:
            double substraction = num_1 - num_2;
            System.out.print("Answer:" + substraction);
            break;
        case 3:
            double multipiclation = num_1 * num_2;
            System.out.print("Answer:" + multipiclation);
            break;
        case 4:
            if (num_2 == 0) {
                System.out.print("Error!!!");
            } else {
                double divison = num_1 / num_2;
                System.out.print("Answer:" + divison);
            }
            break;
        case 5:
            if (num_2 == 0) {
                System.out.print("Error!!!");
            } else {
                double remainder = num_1 % num_2;
                System.out.print("Answer:" + remainder);
            }
            break;
        default:
            System.out.print("Bye");
            break;
        }
    }
}
